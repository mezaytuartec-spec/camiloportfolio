# Camilo Meza Ytuarte — Motion design for SaaS

Bilingual (ES / EN) portfolio. Next.js + Tailwind CSS.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

- Copy and projects: `lib/content.ts`
- Videos and posters: `public/work/`
- Language: toggle in the nav, or `?lang=en` / `?lang=es`
